One funny line in the voice of a smug, judgmental self-checkout machine — the sort of remark the till would aim at a shopper buying energy drinks and instant noodles at 3am. A program that writes that single line to `/output/entry.txt` for make.fun's "The Self-Checkout Is Judging You" bounty.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
